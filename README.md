# Job Application Tracker

A simple job application tracker that records job titles, company names, and application dates in Google Sheets.
![picture of what the extension looks like](https://github.com/yikesssss/Job-Tracker/blob/main/demoPicture.png?raw=true)

## Features
- Record job titles and company names.
- Automatically capture application dates.
- Store application data in Google Sheets.

## Tech Stack
- JavaScript, HTML, CSS
- Google Apps Script
- Google Sheets
